A Vite + React website for EMS Burger.

## Prerequisites
Before you start, make sure you have:
- Node.js 18 or newer
- npm
- A modern web browser

## Quick Start
From the project root, run:

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:3001
```

## Build for Production
To create a production build:

```bash
npm run build
```

To preview the built app locally:

```bash
npm run preview
```

## Notes
- If port 3001 is already in use, Vite will prompt you with the next available port.
- If you run into installation issues, delete the existing node_modules folder and run `npm install` again.
