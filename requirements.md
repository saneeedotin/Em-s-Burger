# Requirements

## Project Overview
This project is a Vite + React web app for EMS Burger.

## Prerequisites
Before running the project locally, install:
- Node.js 18 or newer
- npm
- A modern web browser

## Local Setup
From the project root, run:

```bash
npm install
npm run dev
```

The local development site should open at:

```text
http://localhost:3001
```

## Production Build
To create a production build:

```bash
npm run build
```

## Notes
- If the default port is busy, Vite will suggest another local port.
- No additional environment variables are required for the default local setup.
